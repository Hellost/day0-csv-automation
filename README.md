# 未対応顧客抽出ツール

営業管理CSVから、対応状況が「未対応」の顧客だけを抽出します。

## 想定する利用者

ExcelやCSVで営業案件を管理している小規模事業者。

## 解決する問題

未対応案件を目視で探す作業を自動化し、対応漏れを減らします。

## 使い方

1. `input.csv`を用意する
2. ターミナルで`python main.py`を実行する
3. 生成された`follow_up.csv`を確認する

## 入力項目

- 会社名
- 担当者
- メール
- 対応状況

## 注意事項

- 個人情報や実在顧客のデータを公開リポジトリへ保存しない
- 列名が変更されると現在のコードは動作しない
- 入力値が「未対応」と完全一致する行だけを抽出する
